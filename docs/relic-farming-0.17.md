# Relic farming — 0.17

The player loop is choose a hunt, collect the missing fragments, return and upgrade. The farming screen separates three states: farming required, ready to upgrade, and maximum rank. Upgrade remains an explicit spending decision because runes share fragments.

Each available enemy retains its portrait and regional mechanic. Cards show fragments per win, current-build risk, total wins needed, the next batch (up to 100), cumulative meal estimate, duration and base yield. A one-fight preparation route is always available. Trial first-clear bonuses are explicitly excluded from the target estimate.

The fixed footer offers the real upgrade command when affordable, with combat restrictions retained. On success it refreshes the next goal. Maximum rank never requests fragments for a nonexistent eleventh rank; optional farms and rune upgrades remain accessible. Relic cards show the current and next equipped bonus.

No save schema or economy changes. Forecasts remain estimates: misses, critical hits and supplies can change results. Hunt targets are snapshots; returning to the screen refreshes them.
