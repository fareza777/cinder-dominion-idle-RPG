# Experience upgrade 0.2

Implement solo, keep verification compact, preserve existing saves. English is the default; pre-0.2 saves receive the English default once. Scope: first launch and all five screens, without claiming completion of the full content roadmap.

Flow: short splash → main menu (Continue, New Game, How to Play, Settings) → skippable three-scene illustrated cinematic → four-card onboarding → contextual, progress-driven journey guide. The guide always states a goal, why it matters, exact next action, and completion count. It remains available during gathering, crafting and fighting. Completed steps advance from actual game state, never from tapping Next.

New Game replaces progress only after an explicit in-game confirmation and durable archived backup. Menu time is included in catch-up on Continue. No new save is created just by launching the app. Audio, settings and save errors remain visible through transitions.

Settings: display/audio, language, backups, replay tutorial/intro, About and licenses, native Android Share with clipboard fallback, Rate with honest unavailable state until an actual store URL is configured. No invented public listing or automatic message sends.

Quality improvements: English system feedback/lore, contextual recipe requirements and output, live journey updates, route toward each enemy unlock, consumable explanation, specific queue progress labels and stronger empty states. Validation limited to startup/build, targeted lifecycle/progression assertions and visual captures.
