# Hunt mastery 0.20

Four enemy-specific ranks at 10/25/75/150 wins. Each rank grants +1 attack before armor against that enemy and +1 gold per victory. Fragment bonuses are +1 at rank 2 and +2 total at rank 4. Bonuses start on the fight following the milestone victory.

Existing kill counters are the source of truth: old wins count, no save schema change, no claim flags or retroactive payouts. Combat forecast uses the real damage function. Reward forecasts split across milestone boundaries; fragment planning finds the minimum wins including future rank yields. Time and food estimates use current build strength, excluding future mastery attack gains. Trial first-clear bonuses remain separate.

The collection is available from Explore, Journey and Farm. It sorts available enemies by remaining wins, shows four reward tiers and opens the next hunt batch directly. Existing portraits are reused.
